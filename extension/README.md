# SyncRbx

The official VS Code extension for SyncRbx. 
A free tool to sync VS Code with Roblox Studio. Instant bidirectional sync, SyncRbx Cloud, and Auto-Folders.

## Links
- **Website:** [https://www.syncrbx.xyz/](https://www.syncrbx.xyz/)
- **Documentation:** [https://www.syncrbx.xyz/docs](https://www.syncrbx.xyz/docs)
- **Community (Discord):** [https://discord.gg/jgM2zNuYsN](https://discord.gg/jgM2zNuYsN)

## Features
- **Zero Configuration:** Starts the SyncRbx Node.js server automatically.
- **Auto Setup:** Automatically creates your `src` folder if missing.
- **Smart Status:** Provides an intuitive status bar to monitor your connection to Roblox Studio.

## Requirements
- **SyncRbx CLI**: This extension acts as a frontend for the open-source SyncRbx CLI. It must be installed globally (`npm install -g syncrbx`).
- **Roblox Plugin**: You must install the [SyncRbx Sync Roblox Plugin](https://create.roblox.com/store/asset/92888643849408) to receive code in Studio.

## Usage
1. Open your workspace.
2. Click **SyncRbx: Off** in the status bar at the bottom right.
3. Open Roblox Studio, click the SyncRbx plugin, and click **Connect**.
4. Start coding!
